# loci_focus — MAFB / EMX2 locus analyses on the avian363 alignment

Locus-level comparative analyses of Glut-RA and GABA-4 DARs at MAFB (and EMX2):
paired motif-vs-rest phyloP, regulator motif comparisons, motif site gains and their
placement on the avian363 tree, and compact per-site alignment figures.

## Where this code came from, and where it runs

Copied from `/private/warm-archive/colquittlab/assembly/cactus/avian363/phyloP_matched/loci_focus/`
(2026-11-10). Only code and docs are tracked here; every input and output stays on
warm-archive. Scripts use absolute paths (`F = ".../phyloP_matched/loci_focus"` and the
like), so running a script from this checkout reads and writes the warm-archive copy,
not the repo. Data intermediates (DAR sets, FIMO hits, MAFs, `maf_switch/data*`) are not
in git.

`INDEX.md` is the results index generated by `make_index.py`: every output, filed by the
span it was computed on. Paths in it are relative to the warm-archive directory.

## Spans

`span.py` is the single definition of the analysis spans and routes every output:

- **default** — the gene-bounded DHX35–TOP1 domain, chr20:12,551,036–13,547,533
  (118 DARs; a DAR counts if it overlaps). The bLonStr1 Hi-C places a contact domain at
  ~12.56–13.47/13.55 Mb, matching it.
- **±1.5 Mb** — MAFB ±1.5 Mb (285 DARs), reported alongside the default for power; outputs
  tagged `_1p5mb` / `mafb_1p5mb`.

DAR classes come from `phyloP_matched/dar_sets/`: RAup (Glut-RA vs Glut-Arco-1) and G4up
(GABA-4-1 vs GABA-1-1), with the 4,520 elements up in both dropped, giving mutually
exclusive `RA_over_Arco` / `GABA4_over_GABA1` sets of 501-bp consensus elements
(`allelem_cls.bed`).

## Layout

- top level — span definitions, phyloP pairing (`paired_core.py`, `tf_core.py`), regulator
  motif construction (`build_scenic_motifs.py`, `build_motif_panel.py`), outlier and
  locus tests, plotting, report builder (`build_ar_report.py`), output routing
  (`make_index.py`, `reorg_*.py`).
- `maf_switch/` — motif presence across genomes (`presence.py`: reference projection,
  80% motif coverage, missing ≠ absent), site-gain tables (`rebuild_gain.py`), gain
  placement and rate test on avian363 (`tiers363.py`), gain trees (`gain_trees.py`,
  `gain_trees363.py`), and the per-site alignment figure (`plot_site_alignment.py`,
  incl. `--paper` figure-size output).
- `sens/` — per-matrix sensitivity scans (SCENIC+ cluster members and HOMER motifs).
