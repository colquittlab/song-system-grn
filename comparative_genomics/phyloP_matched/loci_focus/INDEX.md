# loci_focus results index

Every result, filed by the span it was computed on. Generated by `make_index.py`;
moves are logged in `results/MOVES.tsv` (old path → new path).

## Spans

- **`genome_wide/`** — All Glut-RA and GABA-4 DARs genome-wide.
- **`mafb_1p5mb/`** — MAFB gene +/-1.5 Mb (285 DARs, `vgp577/lifted/mafb_1mb.txt`). **Every "MAFB" / "at MAFB" label in these figures and every `_MAFB` filename means this span, not the domain.**
- **`mafb_domain/`** — The default span: the gene-bounded DHX35-TOP1 domain, chr20:12,551,036-13,547,533 (118 DARs; a DAR counts if it overlaps).
- **`emx2_1p5mb/`** — EMX2 gene +/-1.5 Mb (`vgp577/lifted/emx2_1mb.txt`).
- **`compare_gw_mafb1p5mb/`** — Genome-wide and MAFB +/-1.5 Mb side by side in one figure or table (usually panel/row A genome-wide, B at MAFB).
- **`compare_domain_mafb1p5mb/`** — The domain and MAFB +/-1.5 Mb side by side (domain = left panel / first table).
- **`compare_mafb_spans/`** — Several MAFB spans: domain, gene +/-500 kb, +/-1 Mb, +/-1.5 Mb, genome-wide; and the sliding/size-sweep windows.
- **`compare_gw_mafb_emx2/`** — Genome-wide, MAFB +/-1.5 Mb and EMX2 +/-1.5 Mb.
- **`compare_gw_domain/`** — Genome-wide and the DHX35-TOP1 domain side by side.
- **`regulator_motifs/`** — How each MAFB regulator's matrix was chosen from SCENIC+'s own motif evidence (not a span).

Outputs are routed by `span.py`: `result(name, span)`, `track(name, span)` and `per_site(collection, site)` -- new scripts should use them rather than writing to the top level.

Notes:

- The ±1.5 Mb set is the gene ±500 kb locus expanded by 1 Mb. `locus_contrast.py` labels it "±1Mb" (±1 Mb of the locus); it is the same 285-DAR set.
- Site-gain results (`tf_gain_*`, `ar_gain_*`, gain trees, `fig_tf_gain*`) use the corrected presence call (`maf_switch/presence.py`, 2026-11-08). Gain placement (the `tier` column, the ranking figure's second measure, the rate test) is on the avian363 tree (`maf_switch/tiers363.py`): stem, near-stem (the four backbone nodes still holding >=90% of oscines), within, inherited. The 74-way gain trees in `per_site/gain_trees_*` lack basal oscines, so their 'oscine stem' is the core-oscine stem.
- Not moved: pipeline inputs and intermediates (DAR sets, FIMO hits, per-element `.tab` files, FASTA, MAFs, `maf_switch/data*`, tree manifests). Scripts read them back, and most span several regions.
- `scripts_before_reorg/` holds every script as it was before the reorganization.
- Regulator comparisons use `tf_scenic.meme`: one matrix per regulator, AR included, chosen from SCENIC+'s motif evidence for its cistrome (`build_scenic_motifs.py`). NR3C2 shares AR's matrix and is reported as AR. The superseded `tf13.meme`-based results are in `superseded/tf13_motifs_2026-11-09/`. `maf_switch/ascertain_tf*.py` still use the old set and feed nothing downstream.
